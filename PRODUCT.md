# Product

## Register

brand

## Users

Two recruiter populations, one person:

1. **Instrumentation & control engineering recruiters** (UK). Need to see MSc progress, control-loop fluency, signals/thesis work, engineering discipline.
2. **Software / full-stack product engineering recruiters**. Need to see shipped products (Tenora in production, Solana programs, payments), breadth, solo capability.

They land for ~5 seconds and decide whether to scroll. The site's control-transfer switch (INSTRUMENT ⇄ PRODUCT) lets the visitor re-annotate the same document package for their audience without building two portfolios.

## Product Purpose

Get Stephen Carew hired. The portfolio must demonstrate — structurally, not by claim — that he is a rare hybrid: an instrumentation engineer who ships production software solo. Success = recruiter opens the datasheet, flips the switch, and remembers him ("that drawing-sheet site").

## Brand Personality

Precise, warm, redlined. A working engineer's document set: vellum, ink, revision marks, honest stamps. Confident enough to joke gently ("ISSUED FOR: EMPLOYMENT REVIEW"). Never dark-mode-generic, never editorial-magazine, never mono-costume "dev core" aesthetics.

## Anti-references

- Generic AI portfolios: dark ink + display serif + tracked mono kickers + sand accent (the previous version of this site).
- SaaS hero-metric templates, icon-card grids, glassmorphism, gradient text.
- Neondark crypto aesthetics (despite Solana work), terminal-green cosplay.
- Klim-style editorial-typographic lane (second-order AI reflex).

## Design Principles

1. **The document is the metaphor, executed literally.** Title blocks, instrument tags, equipment schedules, revision history, work orders — used the way real drawings use them, not as decoration.
2. **One engineer, two plants.** The transfer switch re-annotates the same system for both audiences; no content is hidden per mode, only emphasis and language.
3. **Show the loop.** Every project gets a control-systems reading (loop note) so the software work proves the instrumentation mind.
4. **Proof by issue.** Claims appear as stamped facts (status, year, live URLs, resume PDF), never adjectives.
5. **Plotter motion.** Lines draw themselves like a pen plotter; nothing fades or bounces decoratively.

## Accessibility & Inclusion

WCAG 2.1 AA. Ink-on-vellum contrast far exceeds 4.5:1. Transfer switch is keyboard-operable with `aria-pressed`; mode persists but page works fully in either mode. All plotter animation gated by `prefers-reduced-motion` (global rule collapses animation durations). No information conveyed by color alone (mode also changes labels).
